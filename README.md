# Portifolio-dev - Thiago e Lucas

Um portfólio pessoal minimalista, responsivo e rápido desenvolvido para apresentar meus principais projetos, habilidades técnicas e experiências como desenvolvedor(a).

---

## ✨ Funcionalidades

- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- **Modo Claro/Escuro (Dark Mode):** Alternância de tema persistente *(remova se não houver)*.
- **Vitrine de Projetos:** Cards interativos com links para o repositório e deploy ao vivo.
- **Seção Sobre & Stack:** Resumo profissional e tecnologias que domino.
- **Formulário de Contato:** Integração direta para mensagens ou links rápidos para redes sociais.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes ferramentas:

- **Front-end:** HTML5, CSS3, JavaScript (ou React / Next.js / Vue)
- **Estilização:** Tailwind CSS (ou CSS Modules / Styled Components)
- **Deploy:** Vercel (ou GitHub Pages / Netlify)
